Pretty, raw and hex views of every message, with the decoded response and original-vs-edited side by side.

Pick the inspector.

The assistant reads one request and its response and reasons about it with you. Choose the backend right in the interface, with ⚙ Model, and switch any time.

  • Local-first & private. A local Ollama model or the Claude Code CLI keeps traffic and keys on your machine; keys are never sent back to the browser.
  • Proposes real requests. When it suggests a test, it writes a complete raw HTTP request. One click sends it through the proxy and feeds the real response back.
  • Yours to steer. Push a proposal straight to Repeater or Intruder; the AI never fires a payload on its own.

Clear it through in a minute.

Windows, macOS (Intel & Apple Silicon) and Linux.

1 · Get the source
git clone https://github.com/0xdak/loupe
cd loupe
2 · Build the binary
go build ./cmd/loupe
3 · Run it
./loupe

What happens next

The proxy (127.0.0.1:8080) and the web interface (127.0.0.1:8081) start together, and the interface opens in your browser.

Click Open browser to launch a profile that already trusts Loupe's certificate, so HTTPS is decrypted with nothing to install. Or point any client at the proxy and import the CA from Proxy settings.

Cross-compile for any target with GOOS / GOARCH. Full flags and notes live in the README.
