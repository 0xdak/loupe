The built-in browser uses its own profile and trusts lightproxy's certificates without installing anything.

Interception

Only in-scope hosts are intercepted (everything when the scope is empty). Browser background services are never intercepted.

CA certificate

To decrypt HTTPS of other applications, install this certificate in the trust store they use. Anyone who has the CA key can read HTTPS traffic of a computer that trusts it: do not share the key and remove the certificate when you are done.

Export CA certificate

Windows (current user only)

certutil -user -addstore Root "%USERPROFILE%\Downloads\lightproxy-ca.crt"

macOS

security add-trusted-cert -r trustRoot -k ~/Library/Keychains/login.keychain-db ~/Downloads/lightproxy-ca.crt

Firefox uses its own store: Settings → Privacy & Security → View Certificates → Authorities → Import.

Through the proxy, the certificate is also served at http://lightproxy/cert.
